# Carrot App 🥕

A Flutter mobile application UI designed for a simple and clean authentication experience.

## 📱 Screens

### Login Screen
- Email input
- Password input
- Forgot Password option
- Login button
- Sign Up navigation

### Sign Up Screen
- Username input
- Email input
- Password input
- Terms of Service
- Privacy Policy
- Sign Up button
- Login navigation

## 🎨 Design

The UI was implemented based on a Figma design.

### Main Features

- Clean and simple UI
- Responsive Flutter layout
- Reusable Flutter widgets
- Login screen
- Sign Up screen
- Custom carrot logo

## 🛠️ Technologies

- Flutter
- Dart
- Material Design
