
# 🥕 Grocery App

A Flutter grocery application UI built based on a Figma design.

## 📱 Screens

### 🔐 Login Screen
- Email input
- Password input
- Forgot Password option
- Login button
- Navigation to Sign Up

### 📝 Sign Up Screen
- Username input
- Email input
- Password input
- Terms of Service
- Privacy Policy
- Sign Up button
- Navigation back to Login

## 🎨 Design

The application UI is inspired by a Figma design and implemented using Flutter widgets.

## 🛠️ Technologies

- Flutter
- Dart
- Material Design
